# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. Older deployments should update to the latest release.

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** private reporting form when enabled. Do not include secrets or exploit details in a public issue. The repository owner must enable private vulnerability reporting and publish a monitored security contact before production launch.

We will acknowledge a private report, investigate its impact, and coordinate disclosure with the reporter. No response time is promised until a monitored contact is established.
